# TakeStack GitHub Pages Fallback

Generated by `script/prepare_github_pages_site.sh`.

Fallback URL: https://dnncha.github.io/takestack-launch/

This package contains the current public product page, privacy notice, and a
retired-page fallback. Legacy beta, founder, direct-download, Product Hunt, and
Stripe campaign pages are intentionally absent so old URLs cannot contradict
the App Store product contract.

Run the dependency-free static QA before publishing changes:

```sh
node scripts/qa-site.mjs
```

The check validates local links and fragments, basic document landmarks,
viewport metadata, image alt text, and the absence of retired purchase claims.
